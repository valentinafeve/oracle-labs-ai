# 2.0.1 Creación de un flujo con Agent Builder

Este laboratorio es la versión introductoria de Agent Builder.

Aquí construirás un flujo simple y funcional para motivarte rápidamente: tomar un mensaje cualquiera y transformarlo en una narración futbolística.

No requiere Data Source, SQL query, Type Convert ni Parser.

---

## 0) Objetivo y tiempo estimado

Objetivo:
1. Construir tu primer flujo funcional extremo a extremo.
2. Entender la diferencia entre `Custom instructions` y `Prompt` del usuario.
3. Validar el flujo en `Playground`.

Tiempo estimado: `10-15 minutos`.

---

## 1) Prerrequisitos mínimos

1. `1. Instalación.md` completado.
2. Login exitoso en Agent Factory.
3. Acceso a `Agent Builder`.

---

## 2) Flujo objetivo (simple)

Este flujo usa 4 nodos:
1. `Chat input`
2. `Prompt`
3. `Agent`
4. `Chat output`

Lógica de conexiones:
1. `Prompt.Prompt message` -> `Agent.Custom instructions`
2. `Chat input.Message` -> `Agent.Prompt`
3. `Agent.Message` -> `Chat output.Message`

Punto clave:
- `Custom instructions` define la personalidad del agente.
- `Prompt` recibe el mensaje real del usuario.

---

## 3) Construcción paso a paso

## 3.1 Crear un nuevo flujo

Qué hacer:
1. En el menú izquierdo, abre `Agent Builder`.
2. Haz clic en `New Flow`.

Qué deberías ver:
- Lienzo vacío listo para agregar componentes.

## 3.2 Agregar `Chat input`

Para qué se usa:
- Captura el mensaje que escribe el usuario.

Qué hacer:
1. En `Components` -> `INPUTS`, arrastra `Chat input` al lienzo.

Qué deberías ver:
- Nodo `Chat input` con salida `Message`.

## 3.3 Agregar `Prompt`

Para qué se usa:
- Define la personalidad y estilo del agente.

Qué hacer:
1. En `Components` -> `INPUTS`, arrastra `Prompt`.
2. En `Template`, pega el texto:

```text
Eres un narrador deportivo experto en fútbol, apasionado y elocuente.
Tu misión es transformar cualquier información o dato que recibas en una
emocionante narración futbolística, como si estuvieras transmitiendo un
partido en vivo por la radio.

No importa si el input es un resultado, una lista de números, un nombre
o cualquier otro dato: conviértelo en una narración dinámica, con emoción
y vocabulario propio del fútbol.
```

Qué deberías ver:
- Nodo `Prompt` con salida `Prompt message`.

Error común:
- Dejar el template vacío o incompleto.

## 3.4 Agregar `Agent`

Para qué se usa:
- Genera la respuesta final usando instrucciones del sistema + mensaje del usuario.

Qué hacer:
1. En `Components` -> `AGENTS`, arrastra `Agent`.
2. Configura:
- `Select LLM to use`: `openai.gpt-oss-120b (oci)`
- `Temperature`: `0.01`
- `Agent description`: `Agent`

Conexiones obligatorias:
1. `Prompt.Prompt message` -> `Agent.Custom instructions`
2. `Chat input.Message` -> `Agent.Prompt`

Qué deberías ver:
- El `Agent` con dos entradas conectadas.

Punto clave:
- Esta separación de entradas es intencional y correcta.

## 3.5 Agregar `Chat output`

Para qué se usa:
- Muestra la respuesta del agente en el chat.

Qué hacer:
1. En `Components` -> `OUTPUTS`, arrastra `Chat output`.
2. Conecta `Agent.Message` -> `Chat output.Message`.

Qué deberías ver:
- Flujo completo conectado de extremo a extremo.

## 3.6 Guardar el flujo

Qué hacer:
1. Haz clic en `Save`.

Qué deberías ver:
- Flujo guardado sin errores.

---

## 4) Probar en Playground

Qué hacer:
1. Abre `Playground`.
2. Envía estas entradas de prueba:
- `3 - 1`
- `Messi, Mbappé, Vinicius`
- `El partido duró 90 minutos y hubo 4 tarjetas amarillas`

Qué deberías ver:
- Respuestas con tono narrador futbolístico, sin errores de ejecución.

---

## 5) Criterio de pase (Gate A)

Este gate se valida ejecutando pruebas en `Playground`.

Debe cumplirse:
1. El flujo corre end-to-end sin errores.
2. El `Prompt` sí modifica el estilo del `Agent`.
3. En al menos 2 de 3 pruebas, la respuesta mantiene tono futbolístico narrativo.

Mini matriz de validación:
1. Entrada: `3 - 1`
- Esperado: narración con mención clara del resultado.
2. Entrada: `Messi, Mbappé, Vinicius`
- Esperado: narración que convierta nombres en relato deportivo.
3. Entrada: `El partido duró 90 minutos y hubo 4 tarjetas amarillas`
- Esperado: narración basada en esos datos, sin SQL ni base de datos.

---

## 6) Troubleshooting básico

1. Responde sin estilo narrador:
- Revisa conexión `Prompt.Prompt message` -> `Agent.Custom instructions`.

2. No responde nada en chat:
- Revisa conexión `Agent.Message` -> `Chat output.Message`.

3. Respuestas muy variables:
- Verifica `Temperature = 0.01` en el `Agent`.

4. Error general de ejecución:
- Guarda de nuevo el flujo y recarga Playground.
